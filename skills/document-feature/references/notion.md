# Destino Notion

Leia este arquivo só quando o destino for Notion.

- **Leitura**: `notion-fetch` na página de destino (confere também que é a página correta)
- **Gravação, página existente**: `notion-update-page` com o conteúdo completo consolidado
- **Gravação, página nova**: `notion-create-pages` sob a página ou banco que o usuário indicou
- Cenários em blocos de código com linguagem `gherkin`
- Título com prefixo da plataforma e funcionalidade (ex: "NSRE — Resseguro — Relatório")
- Dado sensível: pergunte se a página precisa de permissões restritas
